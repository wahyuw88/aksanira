# AKSANIRA Web App v2.7

Paket ini melanjutkan v2.6 dengan perbaikan jalur konversi, preview ilustratif produk, penjelasan pembelian, CTA kontekstual artikel, konsistensi bahasa, dan peningkatan aksesibilitas dasar.

## Sebelum deployment
1. Cadangkan deployment aktif dan deploy ke Vercel Preview terlebih dahulu.
2. Ganti/tingkatkan preview ilustratif dengan screenshot aktual yang diambil dari workbook final; jangan menyebut tabel ilustratif sebagai screenshot produk.
3. Buat listing Mayar untuk Family & Wedding Command Center dan paket lengkap hanya setelah harga, file, dan ketentuan final ditetapkan.
4. Uji seluruh tautan Mayar, checkout, email penerima, dan pengiriman file.
5. Uji Formspree sampai pesan diterima di inbox yang benar.
6. Periksa tampilan desktop/mobile, navigasi, formulir, tabel, keyboard, dan halaman 404.
7. Periksa pengaturan privasi aktual di Formspree, Mayar, dan Vercel.
8. Jalankan Lighthouse, pemeriksaan aksesibilitas, sitemap/robots/canonical, dan verifikasi HTTPS/redirect pada deployment.

Website tetap berupa static HTML. Tidak ada akun pengguna, database, sinkronisasi workbook otomatis, kolaborasi real-time, notifikasi, kalender, atau pemrosesan pembayaran internal.
