AKSANIRA — WEDDING DAY RUNDOWN PLANNER WEB PATCH v1

TUJUAN
Menambahkan produk kelima ke katalog website AKSANIRA dan membuat halaman detail SEO-friendly.

FILE DALAM PATCH
- produk.html: katalog diperbarui dari 4 menjadi 5 produk dan menambahkan kartu Wedding Day Rundown Planner.
- wedding-day-rundown-planner.html: halaman detail produk baru.

STATUS PRODUK
Produk ditampilkan sebagai "Segera Hadir". Harga, file final, dan checkout belum ditawarkan. Ini disengaja agar website tidak menjanjikan produk yang belum selesai.

CARA PENERAPAN
1. Ekstrak ZIP ke root website.
2. Ganti produk.html yang lama dengan versi patch.
3. Tambahkan wedding-day-rundown-planner.html ke root website.
4. Pastikan link /produk.html dan /wedding-day-rundown-planner.html dapat dibuka setelah deploy.
5. Setelah produk final siap, perbarui status, harga, daftar file, preview, dan CTA.

SEO
- Title: Wedding Day Rundown Planner: Susun Acara Hari H | AKSANIRA
- Meta description memuat wedding day rundown planner, susunan acara pernikahan, timeline hari H, PIC, dan koordinasi vendor.
- Canonical menggunakan URL halaman produk.
- H1 fokus pada manfaat utama, heading H2/H3 menjelaskan isi dan kegunaan.
- Gunakan URL yang sama saat produk siap dijual agar sinyal SEO tidak terpecah.

CATATAN
Patch ini hanya menambahkan listing dan halaman pengenalan produk ke website. Workbook Excel/PDF produk belum dibuat, checkout belum diaktifkan, dan deployment tidak dilakukan.
