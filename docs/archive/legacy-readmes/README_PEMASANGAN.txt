AKSANIRA — PATCH WEB FAMILY & COMMITTEE COORDINATOR v1

PATCH TERPADU
Paket ini menyertakan katalog 8 produk serta halaman detail untuk tiga produk tambahan:
- Wedding Payment & Vendor Tracker
- Wedding Documents & Administration Planner
- Wedding Family & Committee Coordinator

CARA PEMASANGAN
1. Backup folder website saat ini.
2. Ekstrak seluruh isi ZIP ini.
3. Salin semua file ke root website (folder yang sama dengan index.html), timpa produk.html dan sitemap.xml.
4. Pastikan seluruh halaman detail di dalam ZIP berada di root website.
5. Commit dan push perubahan ke repository GitHub yang terhubung ke Vercel.
6. Setelah deployment selesai, uji:
   /produk.html
   /wedding-payment-vendor-tracker.html
   /wedding-documents-administration-planner.html
   /wedding-family-committee-coordinator.html
