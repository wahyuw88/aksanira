# AKSANIRA Web App v2.6

Paket ini melanjutkan v2.5 dengan perbaikan konsistensi navigasi, komunikasi merek, halaman kontak, bukti produk, penawaran bundel, CTA tools, dan penjelasan privasi.

## Deploy
Unggah isi folder website ke proyek Vercel yang sama setelah mencadangkan deployment aktif. Uji melalui Preview Deployment sebelum mempromosikan ke production.

## Pemeriksaan wajib sebelum publikasi
1. Kirim formulir kontak uji dan pastikan pesan masuk ke inbox yang benar.
2. Uji transaksi Mayar dan file delivery untuk setiap produk yang tersedia.
3. Periksa tampilan desktop dan mobile serta semua navigasi.
4. Tambahkan screenshot aktual Vendor Decision System dan Family & Wedding Command Center setelah diambil dari workbook final.
5. Tinjau kebijakan privasi dengan pengaturan aktual Formspree, Mayar, dan Vercel.

Tidak ada klaim bahwa situs telah dideploy atau checkout telah diuji.
