# AKSANIRA Web App v2.5

Paket statis untuk deployment Vercel. File entrypoint tetap `index.html`; konfigurasi `vercel.json` dipertahankan.

## Deployment
1. Cadangkan deployment aktif.
2. Unggah seluruh isi folder ini ke proyek Vercel.
3. Pastikan domain canonical `www.aksanira.my.id` dan redirect apex tetap berjalan.
4. Uji navigasi, halaman produk, tools, formulir kontak, dan seluruh checkout Mayar sebelum mengumumkan versi baru.

## Catatan penawaran
Tiga produk unggulan tetap: Financial Control System, Vendor Decision System, Family & Wedding Command Center. Complete Wedding Planning System adalah bundel, bukan SKU tambahan. Checkout Family Command Center dan bundel belum tersedia dalam paket ini.
