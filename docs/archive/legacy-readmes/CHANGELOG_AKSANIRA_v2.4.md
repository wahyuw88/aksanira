# AKSANIRA Web App v2.4 — Portfolio & Conversion Update

## Strategi produk
- Mempertahankan tepat tiga produk unggulan: Financial Control System, Vendor Decision System, dan Family & Wedding Command Center.
- Memperkenalkan posisi bundel `AKSANIRA Complete Wedding Planning System` sebagai paket gabungan tiga workbook, bukan SKU keempat.
- Menempatkan guest list, checklist/readiness, dan timeline sebagai alat bantu pendamping.

## Perubahan halaman
- Homepage: menyelaraskan tiga tools gratis dengan tiga area keputusan inti dan memperjelas CTA menuju katalog produk.
- Halaman Produk: menambahkan bagian bundel, penjelasan alur penggunaan lintas sistem, keterbatasan pemindahan data manual, serta area tools pendukung.
- CTA bundel diarahkan ke halaman kontak karena tautan checkout bundel belum tersedia; tidak dibuat tautan pembayaran fiktif.
- Keterangan Family & Wedding Command Center menyatakan status ketersediaan secara transparan.

## Batasan dan QA
- Tidak ada perubahan backend atau integrasi checkout.
- Harga bundel tidak ditetapkan karena belum ada keputusan harga dan checkout resmi.
- Tidak mengklaim sinkronisasi otomatis, notifikasi, kalender, pembayaran, atau kolaborasi real-time.
- ZIP integrity dan pemeriksaan sintaks HTML dasar dilakukan. Belum dilakukan pengujian visual lintas browser/perangkat, pengujian link secara live, checkout end-to-end, atau deployment produksi.
